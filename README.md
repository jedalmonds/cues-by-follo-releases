# Cues by Follo — releases

Installers and update files for **Cues by Follo**, the live click, spoken cues and multitrack player from [Follo](https://www.follo.cc).

Installed copies check this repository for updates (Settings → Updates). To install by hand, download `Cues-by-Follo-Setup-<version>-x64.exe` from the latest release.

This repository holds only release files; the app's source is private.
